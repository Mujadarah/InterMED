# Security Policy

## Reporting a vulnerability

Do not open a public issue for a vulnerability or for any report containing sensitive data. Use GitHub's private vulnerability reporting feature for this repository.

Never include patient data, credentials, access tokens, device identifiers, or private clinical records in a report.

## Supported versions

InterMED is pre-release software and currently has no clinically supported release. Security fixes will target the latest development version until a versioned support policy is published.
